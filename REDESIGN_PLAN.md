# SIMONAS Redesign Plan — Laravel 12 + Inertia + React + Glassmorphism

Dokumen ini mendesain arsitektur, design system, layout, dan rencana migrasi dari **Laravel 10 + Blade + jQuery + Bootstrap 4** ke **Laravel 12 + Inertia + React + TypeScript + Tailwind** dengan tema **Serene Academic Glassmorphism** (referensi `design/` folder).

**Brand**: SIMONAS (dipertahankan). Tagline tambahan dari design: _"Academic Sanctuary"_.

---

## 1. Tech Stack Final

| Layer | Pilihan | Alasan |
|---|---|---|
| Backend | Laravel 12 + PHP 8.3 | LTS-modern, sudah di jalur upgrade |
| Auth web | Laravel Breeze (Inertia + React stack) | Scaffold otentik, generated by Laravel team |
| Auth mobile | Sanctum personal access token | Sudah dipakai di `/api/v2/*` |
| Frontend | React 18 + TypeScript | Komponen modern, type-safe |
| Bridge | Inertia.js (Laravel adapter + React adapter) | 1 codebase, file-based pages |
| Bundler | Vite 5 | Fast HMR |
| CSS | Tailwind CSS 3 + custom config dari DESIGN.md | Glassmorphism utility-first |
| Komponen UI | **Custom built** (bukan shadcn default) — match dengan mockup `design/` | Mockup punya gaya unik, shadcn default tidak match |
| Ikon | Material Symbols Outlined + Lucide | Mockup pakai Material Symbols |
| Form | React Hook Form + Zod | Validasi client + type inference |
| Tabel | TanStack Table v8 | Pengganti DataTables |
| Chart | Recharts | Donut/line chart sesuai mockup |
| Editor | TipTap | Pengganti Summernote / TinyMCE |
| Tanggal | date-fns | Pengganti Moment.js |
| State client | Zustand (minor) | Modal/sidebar state |
| Toast | Sonner | Pengganti SweetAlert2 |
| Calendar | FullCalendar v6 React | Existing fitur dipertahankan |

**Yang dibuang total**: jQuery, Bootstrap 4, Mix, DataTables, Select2, Summernote, TinyMCE 5, SweetAlert2, MetisMenu, ApexCharts, Flot, semua jQuery plugin, semua Blade view di `resources/views/` (kecuali 1 root `app.blade.php` untuk Inertia bootstrap).

## 2. Arsitektur

```
┌─────────────────────────────────────────────────┐
│            Browser (Chrome/Firefox)             │
│  ┌───────────────────────────────────────────┐  │
│  │ React 18 + Inertia Client                │  │
│  │ - Pages dari resources/js/Pages          │  │
│  │ - Tailwind + custom glass components     │  │
│  └────────────┬──────────────────────────────┘  │
└───────────────┼─────────────────────────────────┘
                │ HTTP (Inertia request)
                ▼
┌─────────────────────────────────────────────────┐
│             Laravel 12 (single server)          │
│  Web routes → Inertia controllers → Eloquent    │
│  /api/v2/*  → JSON (mobile)                     │
└─────────────────────────────────────────────────┘
                │
                ▼
              MySQL
```

### Prinsip
- **Web app pakai Inertia** — tidak ada REST untuk web
- **Mobile app pakai REST API** (`/api/v2/*` yang sudah ada, dipoles)
- **Auth sama**: `users` table sama, Sanctum untuk mobile, session cookie untuk web
- **Build**: `npm run build` → `public/build/` (commit & deploy ke shared hosting)

## 11. Hosting & Deployment

### Build & Deploy ke Shared Hosting
1. Lokal: `npm run build` → `public/build/`
2. Commit `public/build/` ke git (atau pakai post-deploy build di CI)
3. Push ke server via Git/FTP
4. Server: `composer install --no-dev --optimize-autoloader`
5. Server: `php artisan migrate --force`
6. Server: `php artisan optimize`

### Folder shared hosting
Production document root biasanya `public_html/`. Symlink atau salin isi `public/` ke `public_html/`, atau ubah path di server config.

### Future-proof
Pindah ke VPS/Docker/CI tidak butuh rewrite — tinggal containerize.

## 12. Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
|---|---|---|
| Belajar React + Inertia + TS | Slowdown awal 1-2 minggu | Mulai Fase 2 dengan mockup pixel-match (low-risk, high-reward) |
| Glass effect di browser lama (IE/old Safari) | Visual rusak | Backdrop-filter punya fallback solid bg di CSS |
| Material Symbols lazy load delay | Icon flash/missing | Preload font + fallback emoji |
| Captcha math di SPA | UX kurang | Tetap server-side, refresh tanpa reload via Inertia partial |
| Export Excel | Fitur kritikal | Maatwebsite tetap di backend, trigger via download link biasa |
| FullCalendar v3 → v6 React | Breaking | Migrasi terakhir, dedicated time |
| Build asset besar (Lexend + Manrope + Material Symbols) | Halaman lambat | Preload critical, lazy load non-critical, code-split per page |
| Shared hosting | Deploy gagal | Test staging dulu, build di lokal |
| 6 mockup tidak cover semua halaman | Konsistensi visual | Extrapolasi via design system token + existing mockup pattern; review pertama page extrapolated sebelum lanjut |
| Hafalan + Leaderboard fitur baru tanpa data prod | Empty UI awal | Seeder dummy + onboarding empty state yang ramah |
